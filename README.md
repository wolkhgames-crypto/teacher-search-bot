# Teacher Search Bot

Telegram бот для поиска преподавателей в расписании колледжа.

## Возможности

- Поиск преподавателя по фамилии
- Параллельные запросы с автоматическими повторными попытками
- Без авторизации (работает через публичное расписание)

## Требования

- Python 3.9+
- Установленные зависимости из requirements.txt
- Telegram бот токен (получить у @BotFather)

## Установка

1. Клонировать репозиторий:
```bash
git clone <repo_url>
cd teacher-search-bot
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Создать файл `.env` с токеном бота:
```env
BOT_TOKEN=your_telegram_bot_token_here
```

4. Запустить:
```bash
python teacher_bot.py
```

## Использование

1. Отправьте `/start` боту
2. Введите пароль для доступа
3. Отправьте фамилию преподавателя
4. Бот покажет расписание преподавателя

## Деплой

Рекомендуется использовать Docker или PM2 для production.

# SRMK Teacher Search Bot

Telegram бот для студентов СРМК (Ставропольский ракетно-космический колледж).

## Возможности

- 📊 **Оценки** - просмотр оценок из электронного дневника
- 📋 **Расписание** - расписание занятий для группы П-21
- 👁️ **Поиск преподавателя** - найти все пары преподавателя по всем группам

## Быстрый старт

### 1. Переменные окружения

Создай файл `.env`:
```env
BOT_TOKEN=your_telegram_bot_token
```

### 2. Установка

```bash
pip install -r requirements.txt
```

### 3. Запуск

```bash
python bot.py
```

## Использование

1. Отправь `/start` боту
2. Введи пароль администратора
3. Используй кнопки для доступа к функциям

## Зависимости

- aiogram >= 3.15.0
- aiohttp
- beautifulsoup4
- python-dotenv
